# Beyond the Résumé — photos

Drop photos into the matching folder:

- `draw/` — mandalas, sketches, artwork
- `standup/` — stand-up shows, open mics, comedy nights
- `explore/` — food, cafés, restaurants

Then open `index.html`, search for `BEYOND THE RÉSUMÉ — PHOTO LISTS`, and add one line per photo:

```js
{ src: "images/beyond/draw/mandala-01.jpg", alt: "Blue and gold mandala", caption: "Midnight mandala" },
```

Delete the `{ placeholder: ... }` lines once real photos are in. Any number of photos works, and portrait, square and landscape shots all keep their full shape.

Tip: resize photos to about 1600px on the long side (JPG or WebP) so the page stays fast.
